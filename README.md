# بوت تحميل فيديوهات بحد 2 جيجا (Telethon - حساب شخصي)

هذا الإصدار يستخدم حسابك الشخصي على تيلجرام (بدل بوت عادي) عشان يقدر
يرسل ملفات لغاية **2 جيجا** بدل حد 50 ميجا.

⚠️ **تنبيه:** هذا استخدام غير رسمي لحسابك حسب شروط تيلجرام. للاستخدام
الشخصي الخفيف الخطر منخفض، لكن المسؤولية عليك بالكامل.

---

## 1. احصل على API_ID و API_HASH

1. روح لـ https://my.telegram.org وسجل دخول برقم هاتفك (يرسلولك كود على تيلجرام).
2. اضغط **API development tools**.
3. عبّي أي اسم لأي تطبيق (مثلاً App title: MyBot, Short name: mybot).
4. بعد الإنشاء بيطلع لك **api_id** (رقم) و **api_hash** (نص طويل) — احفظهم.

---

## 2. ولّد Session String (على جهازك، مرة واحدة فقط)

هذا يحتاج تشغيله على جهازك الشخصي (كمبيوتر) لأنه يحتاج تفاعل منك
(إدخال كود التحقق).

1. ثبّت بايثون على جهازك إذا ما عندك (python.org).
2. افتح Terminal / Command Prompt واكتب:
   ```
   pip install telethon
   ```
3. حمّل ملف `generate_session.py` (المرفق) وشغّله:
   ```
   python generate_session.py
   ```
4. بيطلب منك API_ID و API_HASH (من الخطوة 1) ثم رقم هاتفك ثم كود
   التحقق اللي بيوصلك على تيلجرام.
5. بالنهاية بيطبع لك سطر طويل جدًا (Session String) — **انسخه واحفظه**،
   هذا يعادل تسجيل دخولك الكامل، لا تشاركه مع أي أحد.

---

## 3. ارفع الكود على GitHub

في نفس مستودعك اللي سويته قبل (`Mybotdown`)، استبدل/أضف الملفات:
- `telethon_bot.py`
- `requirements.txt` (المحدث)
- `Dockerfile` (المحدث)

يمكنك حذف `bot.py` القديم إذا حبيت، أو تركه بدون استخدام.

---

## 4. أنشئ خدمة جديدة على Render (أو عدّل الحالية)

نفس خطوات المرة اللي فاتت:
1. **New + → Web Service** → اختر نفس المستودع.
2. تأكد إن **Language** مضبوط على **Docker**.
3. Instance Type: اختر **$0/month (Free)**.
4. أضف متغيرات البيئة التالية (Environment Variables):
   - `API_ID` = الرقم اللي أخذته من my.telegram.org
   - `API_HASH` = النص اللي أخذته من my.telegram.org
   - `SESSION_STRING` = السطر الطويل اللي طبعه لك generate_session.py
5. اضغط **Deploy web service**.

---

## 5. طريقة الاستخدام

1. افتح تيلجرام على جوالك، روح لمحادثة **Saved Messages** (رسائلي المحفوظة).
2. أرسل رابط فيديو (من X أو أي موقع مدعوم من yt-dlp).
3. البوت (يشتغل بحسابك) بيرد عليك بنفس المحادثة برسالة "جاري التحميل"
   ثم يرسل الفيديو نفسه.

---

## ملاحظات مهمة

- الحد الأقصى 2 جيجا (أو 4 جيجا لو حسابك Telegram Premium — عدّل
  MAX_FILE_SIZE في الكود لو عندك بريميوم).
- لا ترفع `SESSION_STRING` أو `API_HASH` لأي مكان عام؛ خلّيهم فقط في
  Environment Variables على Render.
- لو ظهرت مشاكل تسجيل دخول متكررة أو تنبيه أمني من تيلجرام، هذا طبيعي
  أول مرة تستخدم Session String من سيرفر جديد — وافق على الإشعار من
  جهازك إذا وصلك.
- حدّث yt-dlp بشكل دوري في requirements.txt لأن مواقع التواصل تتغيّر باستمرار.
